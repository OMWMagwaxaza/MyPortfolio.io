An advanced data science project integrating SQL queries within the R environment to analyze over 300,000 flight records from the 2013 NYC flights dataset. Focused on improving airline operations by extracting insights on departure delays, carrier performance, destination trends, and on-time rates — all via SQL executed inside R using sqldf.

DATASET

nycflights13::flights 300,000+ records NYC departures 2013

KEY QUERIES ANSWERED

  • Top 5 flights with the longest departure delays
  • Average arrival delay per airline — worst performers ranked
  • Top 3 destinations by highest average arrival delay
  • Average flight distance per origin airport
  • Daily flight count and average delay throughout January
  • On-time performance % per airline (arrival delay ≤ 0)
  • Flights delayed 60+ mins traveling over 1,000 miles
